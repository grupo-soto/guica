# Guica · web nueva (versión de prueba)

Copia para revisar la web nueva de Guica (portada, tienda y recorridos 3D de los sectores) antes de publicarla en guica.es: https://grupo-soto.github.io/guica/

No sale en Google (noindex). El botón «Corregir» guarda las notas en el servidor de notas del grupo; dentro del 3D, cada nota
lleva el sector y el objeto. En esta copia el pedido y el formulario abren el correo de quien los usa (no hay PHP).
No se edita aquí: se genera desde la carpeta de Grupo Soto con `npm run subir-guica-prueba`.
